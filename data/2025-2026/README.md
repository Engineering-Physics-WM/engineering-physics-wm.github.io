# 2025-2026 Cohort Data

This folder is reserved for public 2025-2026 cohort materials.

Use this folder for:

- `projects.json` plus project detail JSON files in `projects/`
- public project descriptions, advisor/coadvisor information, themes, and workspace notes
- public archive summaries and final public team/project information

Do not put private student records here. Rosters, ranking exports, student emails, private notes, and private team assignment exports should stay in Supabase or in ignored local files.
